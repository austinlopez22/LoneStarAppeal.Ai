# LoneStarAppeals.Ai

LoneStarAppeals.Ai is a React application designed to assist homeowners in Texas in reporting their property information and leveraging AI to help fight property taxes.

## Features

- User-friendly form for homeowners to input property details.
- Integration with AI services to analyze property information and provide insights.
- Responsive design for accessibility on various devices.

## Installation

To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/LoneStarAppeals.Ai.git
   ```

2. Navigate to the project directory:
   ```
   cd LoneStarAppeals.Ai
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To run the application in development mode, use the following command:
```
npm start
```
This will start the development server and open the application in your default web browser.
